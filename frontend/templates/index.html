Distance / proximity

          
    
            
  • ST_Distance(a, b) — distance between two shapes (metres on geography).
    • 
            
  • ST_DWithin(a, b, d) — true if a and b are within distance d (index-assisted).
    • 
          

          
Relationships

          
    
            
  • ST_Within(a, b) — a lies inside b.
    • 
            
  • ST_Contains(a, b) — a contains b (boundary excluded).
    • 
            
  • ST_Covers(a, b) — like Contains, but boundary points count.
    • 
            
  • ST_Intersects(a, b) — a and b share any point.
    • 
            
  • ST_Touches(a, b) — boundaries meet, interiors do not.
    • 
            
  • ST_Crosses(a, b) — e.g. a road passing through an area.
    • 
            
  • ST_Overlaps(a, b) — areas partly overlap, neither contains the other.
    • 
          

          
Nearest neighbour

          
    
            
  • ORDER BY geom <-> point LIMIT k — the k nearest, using the GiST index.
    • 
          

          
Geometry

          
    
            
  • ST_Point(lon, lat) — makes a point (longitude first!).
    • 
            
  • ST_SetSRID(g, 4326) — labels a geometry with its coordinate system.
    • 
            
  • ST_Transform(g, srid) — converts coordinates to another system.
    • 
            
  • ST_AsText(geom) — shows a geometry as readable WKT.
    •
